# Sitio web de la Agencia Creativa Aurora

Este repositorio contiene un landing page moderno para una agencia creativa ficticia llamada **Aurora**. El proyecto está construido con HTML, CSS y JavaScript puro, utilizando un diseño responsive y animaciones sutiles para mejorar la experiencia de usuario.

## Estructura del proyecto

```
Sitio-web/
├── index.html
├── assets/
│   ├── css/
│   │   └── styles.css
│   └── js/
│       └── main.js
└── README.md
```

## Características principales

- Secciones para servicios, portafolio, equipo y contacto.
- Estilos modernos con tipografía Poppins y esquema de colores degradados.
- Menú responsive con botón hamburguesa para dispositivos móviles.
- Formulario de contacto con campos requeridos.
- Actualización automática del año en el pie de página mediante JavaScript.

## Cómo visualizar el sitio

1. Clona el repositorio:

   ```bash
git clone https://github.com/<tu-usuario>/Sitio-web.git
   ```

2. Abre el archivo `index.html` en tu navegador favorito o usa una extensión de servidor local para ver los cambios en vivo.

## Personalización

- Puedes reemplazar las imágenes de Unsplash por recursos propios actualizando las clases `project__image--1`, `project__image--2` y `project__image--3` en `assets/css/styles.css`.
- Ajusta los colores principales modificando las variables CSS definidas en `:root`.
- Para agregar nuevos servicios o miembros del equipo, duplica las tarjetas correspondientes en `index.html`.
